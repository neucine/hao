# Hao brand assets

The primary Hao identity is the **Core** mark: an open modular hexagon containing the runtime `h`, completed by an execution dot.

## Files

- `hao-mark.svg` — primary symbol on transparent background
- `hao-horizontal.svg` — primary horizontal lockup with `TS / JS RUNTIME`
- `hao-app-icon.svg` — dark rounded-square application icon
- `hao-mark-mono-dark.svg` — single-color mark for light backgrounds
- `hao-mark-mono-light.svg` — single-color mark for dark backgrounds

## Palette

- Cyan: `#00DFFF`
- Blue: `#267BFF`
- Violet: `#7B61FF`
- Deep navy: `#0B1020`
- Secondary text: `#667085`

## Usage

Keep clear space around the mark equal to at least half the execution-dot diameter. Do not close the top-right opening, detach the dot from that opening, distort the hexagon, recolor individual edges, or add effects inside the source SVGs.

The SVGs use explicit geometry and render without external image dependencies. The horizontal wordmark uses an `Inter, Arial, sans-serif` font fallback stack; convert the text to outlines before supplying artwork to vendors that require exact typography.
